# 低电量与性能档

## 档位

| 档位 | 触发条件 | 行为 |
| --- | --- | --- |
| 正常 | 电量高于阈值，或正在充电 | 按当前设置运行 |
| 省电 | 电量 ≤ 阈值（默认 20%），或系统省电模式 | 缩短空闲卸载、给出提示 |
| 极低电量 | 电量 ≤ 5% 且未充电 | 提示并建议切到更稳的档位 |

充电中（无论电量）一律按正常档处理，也不会弹低电量提示。

## HTP 性能档

| 选项 | 说明 |
| --- | --- |
| 自动（默认） | 正常时允许 Burst；省电档用均衡；极低电量用省电 |
| 性能优先 | 允许 Burst，首 token 更快；长文生成更容易发热降速 |
| 均衡 | 固定均衡档 |
| 省电 | 固定省电档，不使用 Burst |

Burst 的代价是峰值电流和瞬时热量更高。长文生成时可能先快后慢，整体不一定更快。

## 提示规则（手动档）

- 电量 ≤ 阈值且手动选了「性能优先」：轻提示一次，附「切为均衡」按钮。
- 电量 ≤ 5% 且未充电、仍在用 Burst：强警告，说明可能触发系统关机。
- 充电中：不提示。
- 自动档：不提示，由自动规则处理。

所有提示都只建议、不执行。只有你点按钮才会改设置。

## 永久关闭提示

提示条上有「本次忽略」和「不再提醒」；也可以在「设置 → 推理优化 → 电量与性能档」里分别关闭「低电量提示」和「极低电量警告」。

永久关闭后仍然可以在同一位置看到当前档位与电量，不会变成完全未知。

## 省电时质量怎么保持

- 优先减少轮次与不必要的注入，而不是硬压回答长度。
- 不为了省电去调低 Temperature（那不会省电，只会让回答变僵）。
- 应急场景建议保持更稳的采样：事实优先，必要时明确说「不确定」。
