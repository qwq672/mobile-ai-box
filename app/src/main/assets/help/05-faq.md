# 常见问题

## 回答开始重复、绕圈

- 调高 Repeat Penalty（如 1.15），或把 Repeat 窗口升到 384。
- 降低上下文里无关的历史，长会话建议开新会话。
- 禁用不必要的工具：工具清单越长，小模型越容易分心。

## 幻觉明显

- 先确认是否与工具/提示词注入有关：设置 → 调试 → 纯净聊天，对比同一问题。
- 联网搜索的摘要可能被模型当事实，需要时让它给出处。
- 模型本身的事实知识有限，重要信息建议开启联网或自行核对。

## 模型加载失败

- 设置 → 诊断，看 native 错误与「实际生效」是否异常。
- KV 请求 q8_0 但实际 f16：说明没开 FlashAttention，属于正常降级。
- NPU 失败时先在「框架与模块」里确认插件与设备支持，再回退到 CPU / Vulkan。

## 速度慢

- 线程不是越多越好，先试 2–4 个大核。
- 上下文过长会拖慢 prefill，长会话可开新会话。
- 检查是否在省电档（设置 → 推理优化顶部会显示当前档位）。

## 发热 / 掉电快

- 用「均衡」或「省电」HTP 档，避免长时间 Burst。
- 模型越大越费电；短问答用小模型更合适。
- 设置 → 调试 → 运行日志，按 `aibox.power` 查看档位切换记录。

## 工具调用不触发

- 确认工具已在「设置 → 工具调用」启用。
- 部分小模型对 function calling 的遵循较弱，可以把需求说得更直接。
- 看运行日志的「工具」tag 是否有调用记录与失败原因。

## 日志在哪里

设置 → 调试 → 运行日志，可复制当前视图；页面顶部会显示日志文件目录，便于导出。
