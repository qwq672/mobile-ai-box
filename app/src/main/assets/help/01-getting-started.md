# 上手指南

## 1. 准备模型

打开「模型」页：

- **下载**：从推荐列表挑一个 1B–4B 的 GGUF。第一次不建议直接上大模型。
- **导入**：已有 .gguf 文件时，用本地文件导入。

模型文件越大，质量通常越好，但加载更慢、占用内存更多、耗电也更高。

## 2. 加载并对话

点「加载」后回到聊天页。第一次加载会做一次初始化，耗时明显长于后续对话。

- 本地推理不依赖网络，飞行模式可用。
- 顶部状态条会显示生成速度、上下文占用、后端与温度。

## 3. 需要时再开工具

输入框左侧有一个「联网」按钮，三态循环：

| 状态 | 含义 |
| --- | --- |
| 联网 | 关闭，不访问网络 |
| 阅读 | 只读取你贴的链接 |
| 搜索 | 允许主动搜索并读取网页 |

文件、邮件、手机控制属于高级工具，默认关闭，需要到「设置 → 工具调用」单独开启，并在执行前确认。

## 4. 想更省电

设置 → 推理优化：

- 低电量模式默认开启：电量低于阈值时给出提示，但不会擅自改你选的性能档。
- HTP 性能档：自动 / 性能优先 / 均衡 / 省电。低电量使用「性能优先」时会提示，要不要降档由你决定。

## 5. 遇到问题

设置 → 调试 → 运行日志，先看 `aibox.llama`（推理）和 `aibox.tool`（工具）两个 tag。
