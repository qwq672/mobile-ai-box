# 工具与联网

## 输入区「联网」三态

底层仍是两个独立开关（`web_search`、`url_reader`），输入区只是把常用的组合聚合起来：

| 状态 | web_search | url_reader | 适用场景 |
| --- | --- | --- | --- |
| 联网（关） | 关 | 关 | 闲聊、写作、角色扮演 |
| 阅读 | 关 | 开 | 你贴了链接，只需要读这一页 |
| 搜索 | 开 | 开 | 查资料、核对事实 |

点击循环切换；「设置 → 工具调用」里的两个独立开关仍然有效，状态始终一致。

## 工具选项

部分工具带有自己的选项，在「设置 → 工具调用 → 工具详情」里配置：

- **联网搜索**
  - 默认搜索引擎：自动 / DuckDuckGo / Tavily / Exa
  - 自动：配置了 Tavily 或 Exa 的 API key 就用它，否则用免费的 DuckDuckGo
  - 默认结果条数：1–10，条数越多注入 prompt 越长
- **URL 阅读器**
  - 默认最大长度：1000–10000 字符
  - 是否附带页面链接：便于模型继续探索

模型显式传入参数时以模型参数为准；没传才使用这里的默认值。

## 基础工具 vs 高级工具

- 基础工具：自动执行，无副作用（计算器、时间、设备信息、搜索、读网页）
- 高级工具：执行前需要确认（文件读写、邮件、高级设备信息、手机控制）

高级工具可以加入「自动确认」白名单，但建议只对完全信任的工具开启。

## 工具没有生效？

1. 设置 → 工具调用，确认开关已打开（未启用的工具不会出现在模型可见的工具清单里）。
2. 设置 → 调试 → 运行日志，选 tag「工具」，查看是否有调用与错误。
3. 本地小模型对工具调用的遵循能力有限，提示词里的工具越多，越容易乱选。按需开启即可。
