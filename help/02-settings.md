# 设置说明

## 推理

| 项 | 说明 |
| --- | --- |
| 后端 | CPU / Vulkan / OpenCL / NPU。NPU 需要安装对应插件并适配模型 |
| 线程 | 0 = 自动（按大核数）。端侧 decode 常受内存带宽限制，线程不是越多越快 |
| 批大小 | prompt 阶段一次处理多少 token。调小可削峰值功率，代价是首 token 略慢 |
| KV 量化 | q8_0 / q4_0 需要 FlashAttention 才可能生效，否则会被降级为 f16 |
| 上下文 | 越长越占内存；长文任务再调大，日常 2048–4096 足够 |

设置 → 诊断 里的「实际生效」显示的是 native 侧真实值，例如 `q8_0 → f16（已降级）`。

## 采样

| 项 | 推荐 | 说明 |
| --- | --- | --- |
| Temperature | 0.6–0.8 | 越高越发散，小模型过高更容易胡编 |
| Top-K | 40 | 每步保留概率最高的 K 个候选 |
| Top-P | 0.9–0.95 | 累积概率阈值 |
| Min-P | 0.05 | 只保留相对最大概率不低于该比例的候选；0 = 关闭 |
| Repeat Penalty | 1.1 | 太高会让用词变怪，太低容易复读 |
| Repeat 窗口 | 256 | 参与重复统计的最近 token 数 |

采样改动**即时生效**，不需要重新加载模型。底部有「恢复推荐值」。

## 推理优化

- 标有「加载时生效」的开关需要重新加载模型。
- 标有「暂未消费」的项是预留给插件后端的，当前 llama.cpp 路径不会读取，改了不起作用。
- 强制 FlashAttention 只对 Transformer 模型有效；Mamba / RWKV 会被强制关闭。

## 重置

设置 → 重置：

- 按分类重置：推理参数 / 外观 / 行为与搜索 / 云端 / 工具 / 推理优化
- 重置所有设置：以上全部；模型文件、聊天记录、欢迎页状态保留

所有重置都会先弹确认框。
