## 本版本主要改动(commit a4bedd0)

### 1. 多推理框架配置(混合: 全局默认 + 框架覆盖)
- `FrameworkConfig.kt`: 定义 `FrameworkId` 枚举(LLAMACPP / LITERT / MNN / ONNX / QNN / MLLM)
- `FrameworkConfigRepository.kt`: 持久化框架级覆盖,JSON 存到 DataStore
- 全局 `InferenceConfig` 是默认值,每个框架可选地覆盖部分字段
- 例: LiteRT 框架可强制 ctx=2048 + KV F16,其他框架用全局默认

### 2. 模型加载超时(防卡死)
- `ModelsViewModel.activate`: 加 90s 超时
- 超时自动 `engine.unload()` 并给用户清晰报错
- 不再出现"一直正在加载模型"的永久 loading 状态

### 3. 模块动态检测
- 翻译/图像生成占位页加自动扫描,安装模块后立即可见
- 顶部加刷新按钮支持手动重扫
- 显示状态: 已检测到(名称/版本/包名) / 尚未安装 / 扫描中

### 4. 散热状态 → 设备状态(扩展为综合状态)
- `ThermalMonitor` 新增字段:
  - CPU 利用率(/proc/stat 差分)
  - GPU 主频 + 利用率(kgsl/mali 路径扫描)
  - 系统内存使用率(ActivityManager.MemoryInfo)
  - App PSS + Native 内存(Debug.MemoryInfo)
  - 电量百分比 + 电池温度 + 充电状态
- 2 秒采样一次(温度更实时)
- 详细页新增 4 个 Section: CPU/GPU · 内存 · 电量 · 温度
- 主页/设置卡片加状态摘要行

### 5. 基准测试增强
- `BenchmarkResult` 新增字段:
  - `memUsagePercent` 测试期间系统内存占用率
  - `appPssMb` / `appNativeMb` App 内存峰值
  - `energyEfficiencyTokensPerJoule` 能耗比(每焦耳生成 token 数)
  - `avgCpuUsage` / `avgGpuUsage` 平均 CPU/GPU 利用率
- 基准测试卡片新增第二行显示所有增强指标

### 6. 模块加载器原型(commit 4291a09)
- 完整 manifest 契约(JSON Schema v1.0.0)
- 拓扑排序 + 环检测 + 缺失依赖检查
- Native 库加载器(dlopen + 引用计数 + SONAME 去重)
- LiteRT 安全上下文功能(Gemma 4 E2B=2048 / E4B=1500 默认值)
- 宿主接口预定义(ISessionManager / IContextBudget / IMemoryStore)
- 16 个单元测试

## 安装顺序
1. 先装 `aibox-arm64-v8a-release.apk`
2. (可选)装 `easy-chat-module.apk` / `translate-module.apk` / `litert-backend-plugin.apk`
3. 打开 AIBox,进入「模块管理」可看到所有已安装模块
4. 进入「模型」页导入本地 GGUF 模型,然后开始聊天
